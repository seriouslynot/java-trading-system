# Java 交易实验台 · 本机验收记录

2026-11-13。Apple M1 MacBook Air（8 GB）、macOS 15.7.5、Temurin 21.0.2、Gradle 9.9.1、Node 25.9.0、npm 11.12.1。

## 通过的检查

- Java：`./gradlew build`，核心 62 项、应用 10 项，全部通过。包括订单簿、账本和五类行情的随机不变量，日志重放、末行修复、CRC32 与附录旧版日志样本，运营和对账测试，以及 8 项独立回归指纹。通过临时 Gradle 初始化脚本给核心注入 Spring 运行时依赖，验证 `checkNoFramework` 拒绝直接及传递依赖。
- 前端：`npm run build`、`npm run lint` 通过。JAR 启动后经 HTTP 验证首页和 JS/CSS 静态资源均可获取。
- HTTP：健康检查、部分成交、撤单权限、业务拒绝与格式错误、管理口令、并发时落盘后回复、资金和持仓总量不变。对同一文件实际停止并重启进程后，订单簿、账户、近期成交、分录及幂等结果一致。
- 对账：无注入时无差异；三种种子的独立实验以 1% 注入，识别全部注入，0 漏报、0 误报。在线用 100% 注入做确定性冒烟，确认差异告警触发。
- 流量暴涨：以默认 GROUP 模式，分别在防护全开与全关时请求 5,000 笔/秒、20 秒，两轮各提交 100,000 笔；全开约 79,505 笔限流，全关无快速拒绝，两轮均无超时，结束后对账 0 差异。指标窗口也计入清场撤单，因此指标请求总数可能高于 100,000。
